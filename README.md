
# Redes e Internet

Projeto académico desenvolvido em HTML5 e CSS3, com o objetivo de apresentar conceitos fundamentais sobre redes informáticas e equipamentos de rede.

## Funcionalidades

- Página inicial com introdução às redes informáticas.
- Explicação sobre a Internet.
- Apresentação dos tipos de ligação: Wi-Fi e Ethernet.
- Página dedicada aos equipamentos de rede.
- Cartões informativos com imagens.
- Navegação entre páginas.
- Layout responsivo.

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts (Inter)
